Expected Formats

PCAP / PCAPNG

Standard packet capture files. The system extracts packet headers, TCP flags, payload sizes, and timing information.

CSV (Flow Records)

Flow-level CSV with columns like: timestamp, src_ip, dst_ip, src_port, dst_port, protocol, bytes, packets, duration, flags

Supported schemas: CIC-IDS, CTU-13, UNSW-NB15, CICIoT2023, and generic flow formats.

JSONL (Packet Records)

One JSON object per line with fields: timestamp, src_ip, dst_ip, src_port, dst_port, protocol, flags, bytes_sent, packets, ttl, payload_size, tcp_window, duration

ZIP Archive

Upload a ZIP containing any of the above traffic formats. The system will auto-extract and process the first traffic file found (preferring PCAP > CSV > JSONL).
