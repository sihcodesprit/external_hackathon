# Model Card — LSTM Cyber World Model (SIH-26153)

## 1. Overview

- **Model type:** Recurrent neural network (stacked LSTM) used as a temporal
  **Cyber World Model**.
- **Task:** Learn the network-state transition `P(S_{t+1} | S_t)` and support
  K-step forward forecasting, attack-stage prediction, and counterfactual
  defensive simulation.
- **Package:** `netwatch.models.lstm_world_model.LSTMWorldModel`
- **Interface:** `netwatch.models.base_model.WorldModel` (abstract) — swappable
  with `LinearWorldModel`, and later a Transformer / Temporal GNN, without
  rewriting the pipeline.

## 2. Intended use

- Multi-step network attack forecasting from flow/packet/temporal features.
- Proactive cyber-defence decision support via counterfactual simulation.
- Offline deployment (models are loaded from local files).

## 3. Not intended for

- Point-in-time detection as the sole capability (static baselines are provided
  but are not the primary model).
- Real blocking/mitigation — counterfactuals are **simulation only**.
- Unvalidated real-world claims — see evaluation caveats below.

## 4. Architecture

```
Input sequence [seq_len x n_features]
  → Linear projection → ReLU
  → stacked LSTM (num_layers=2, hidden=64, dropout=0.2)
  → last hidden state
  → dense head → next-state vector [n_features]
```

Loss: MSE on the normalized next-state vector.
Optimizer: Adam (lr=1e-3).

## 5. Input / output

- **Inputs:** temporal sequences of standardized 15-feature `NetworkState`
  vectors. Features: flow (`bytes`, `packets`), packet (`ttl_mean`,
  `payload_mean`, `payload_max`, `tcp_window_mean`), temporal
  (`packets_per_second`, `connection_rate`, `unique_dst_ports`,
  `unique_dst_hosts`, `syn_rate`, `ack_rate`, `rst_rate`, `syn_ack_ratio`,
  `port_entropy`).
- **Output (train):** predicted next standardized state vector.
- **Output (forecast):** per step, a `{step, risk, stage, stage_probability,
  confidence, supporting_features, explanation}` record for the K-step rollout.

## 6. Training data

Synthetic multi-stage attack traces generated by
`netwatch/ingestion.synthetic.generate_trace` (development/demo/testing only).
Real network datasets are **not** part of the shipped training data.

## 7. Performance (synthetic — see EXPERIMENTS.md)

| Setting | Continuous (RMSE / cosine) | Classification (Acc / F1 / AUC) |
|---|---|---|
| Temporal hold-out test | 0.335 / 0.870 | 0.991 / 0.981 / 0.985 |
| Unseen attack stage | 0.521 / 0.747 | 0.928 / 0.508 / 0.898 |

**Caveat:** these numbers are on synthetic data and must not be interpreted as
real-world performance. Real-dataset evaluation is **Not evaluated yet**.

## 8. Ethical & operational considerations

- The model informs **decision support**; a human operator makes final
  mitigation choices.
- Counterfactual actions represent simulated outcomes, not guaranteed real-world
  effects.
- Data, labels, and results are honest: no fabricated metrics.

## 9. Persistence

- Saved via `save(path)` to `data/models/world_model_lstm.pt` (state dict +
  hyperparameters) alongside `feature_scaler.pkl`.
- `load(path)` restores the model for offline inference.
